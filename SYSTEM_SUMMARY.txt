HOW TO USE
================================================================================

DOCTORS:
   1. Open: http://localhost:8000
   2. Type diagnosis: "Patient with fever and cough"
   3. Click: "Search Codes"
   4. View: ICD-10 codes with descriptions
   5. Select: The appropriate code for patient

ADMINISTRATORS:
   1. Monitor health: curl http://localhost:8000/api/health
   2. Test API: curl -X POST http://localhost:8000/api/query...
   3. Check logs: Review Python output
   4. Backup: Copy data.duckdb file
   5. Restart: Kill Python process and restart

TECHNICAL STAFF:
   1. Start server: python -m uvicorn app:app --host 0.0.0.0 --port 8000
   2. Monitor: Check port 8000 is accessible
   3. Debug: Review Python error logs
   4. Maintain: Regular backups and updates
   5. Scale: Configure load balancer if needed
